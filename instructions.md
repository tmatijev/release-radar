ToDo List for the Release Radar Chrome Extension

## Description

This extension is about fetching the data for the movies and TV Series from external
API (free) and allowing users to subscribe to ceratin episodes or movies in order to 
receive the release date and notification when the new episode is coming out.

Extension should allow user to log in with their email address (SSO sign in probably) 
and then search for the upcoming movies or TV series that are not over but "in progress".


## Acceptance Criteria

[ ] - Use some free API access for the movies, TV series where we can fetch the release dates
of the episodes or movies
[ ] - Use SSO Google login with email probably, because we wan't have any our database (or do we need it?)
[ ] - When logged in, we could check our subscribe list and add/remove movies or tv series to our release radar list
[ ] - When we subscribe for some TV series, for example, we should get a notification (and also some notification on the extension icon)
when the new episode is coming on
